# 小猫家园 · 喵喵合成乐

这是一个纯本地的单机合成小游戏，不含联网接口、账号、广告或线上排行榜。游戏主体使用原生 HTML、CSS、JavaScript 和 Canvas 编写，不需要安装依赖，也没有远程字体、图片或音频资源。七个合成角色直接采用你提供的七张卡通图；角色大小较上一版适度增加，并调快投放、提高重力与收紧危险线来增加难度。第六、七个形象碰撞时会触发额外的光环、猫爪粒子和喵声。

## 开始游戏

- 直接双击 `index.html`，断网也可以游玩。
- 最佳分与十佳战绩会存于本地浏览器存储；浏览器隐私模式若禁用本地存储，当前局仍能玩，但关闭页面后记录可能无法保留。
- 鼠标移动后点击投放；手机/触屏可轻触场地或使用场地下方按钮。
- 键盘使用 A / D 或 ← / → 移动，空格投放，R 重新开始。
- 得分、个人最高纪录、十佳成绩和主题偏好只保存在当前浏览器的本地存储中。

## 修改游戏内容

打开 `config.js`，文件顶部有完整说明。可以直接改：

- `text`：页面标题、按钮、提示语和说明文字。
- `theme`：浅色/深色主题的颜色。
- `items`：每级角色名称、表情、分数、碰撞半径及 `mascot` 头像编号；数组顺序就是成长合成顺序。七张头像均为本地 PNG。
- `play`：游戏区域尺寸、结束线、投放间隔和初始物品范围。
- `animation`：重力、球球/墙面弹性、接触摩擦与近距离黏附强度、合成放大动画、震动和粒子效果。
- `sound`：音效开关、音量、音高、长度和喵声参数。喵声由浏览器即时合成，不需要音频文件。
- `animation.specialPair` / `specialColor`：特别碰撞的角色序号和光效色。

顶部游戏标题、说明、按钮和提示文案等均集中在 `config.js` 的 `text`；布局、磨砂玻璃按键和动效样式可改 CSS 文件。头像图片在 `assets/cat-1.png` 至 `assets/cat-7.png`，成长顺序在 `items` 的 `mascot` 字段指定。个人十佳战绩（分数及完成时间）、最佳分和成就都存入当前浏览器 `localStorage`。20 个成就中 3 个隐藏，达成后有勋章动画。游戏结束后可以做 10 词学习与 5 题抽查，答对至少 3 题可复活一次；移除最小的约一半角色。背词词库、词义、例句和词形均在 `word-bank.js`，可离线扩充。

页面排版与视觉细节在 `style.css`、`cat-theme.css`、`polish.css`、`progress.css`、`gameplay.css`、`cat-finish.css` 和 `challenge-polish.css`，页面结构在 `index.html`，游戏机制在 `game.js`。通常只改 `config.js` 就能自定义主要内容，不必改引擎。

精细主题样式在 `cat-theme.css`、`polish.css` 和 `cat-finish.css`；`cat-home.svg` 是可安装应用的图标。声音由 Web Audio 本地合成，投放是轻柔的双音“啪嗒”，合成是带滑音和颤音的喵声。

## 离线缓存

双击 HTML 的方式可直接离线玩。若要使用 Service Worker 离线缓存，或安装到手机，请先将整个项目发布到 HTTPS 网站并在线打开一次；`service-worker.js` 会缓存项目中的本地游戏文件。所有游戏资源仍然都在本项目内。

## 安装到手机

- **Android**：在支持的 Chrome 浏览器打开 HTTPS 发布网址，点页面右上角的安装按钮，或浏览器菜单里的“安装应用/添加到主屏幕”。这是可安装的 PWA，系统会将它作为独立应用窗口启动；当前项目尚未打包成 Play 商店 APK。
- **iPhone/iPad**：在 Safari 打开 HTTPS 发布网址 → 点“分享” → “添加到主屏幕”。这是 iOS 支持的主屏幕网页应用方式，并非 App Store 签名的原生 IPA。
- 安装后，首次成功打开并缓存资源，即可离线玩。用 localhost、HTTPS、GitHub Pages 或静态网页托管均可；纯 `file://` 双击方式不能使用安装和 Service Worker 功能。

本地预览可以用 VS Code Live Server 扩展启动；公开网址需要将本目录下文件部署到静态 HTTPS 托管服务。生成可发布的原生 APK/IPA 还需 Android/iOS 构建工具、签名证书和相应平台账号，不包含在纯网页离线版中。
